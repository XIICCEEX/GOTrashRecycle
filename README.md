โปรเจกต์มินิเกมที่น Design Patterns มาปรับใน Unityให้โค้ดเป็นระบบมากขึ้น

GameConcept
เป็นมินิเกมธีมแยกขยะลดโลกร้อนที่จะให้ผู้เล่นได้มาลองแยกขยะแต่ละประเภทว่าขยะแต่ละแบบก็มีคุณค่าที่แตกต่างกันไปโดยมีความยากก็คือการควบคุมทิศทางของขยะจะไม่เป็นแค่การเดินหน้าถอยหลังอย่างเดียวแต่มีการกดหมุนเพื่อเลือกทิศทางที่ตัวถังขยะจะวิ่งไปเก็บโดยหลบระเบิดหรือก้างปลา(ขยะที่ไม่ใช่ประเภทรีไซเคิล) ที่จะสุ่มออกมาให้เก็บพร้อมกับไอเทมอื่นๆ

Design Patterns ที่ใช้
1) Factory Pattern ในการสร้างไอเท็มตกลงมา
ไฟล์ที่เพิ่มและแก้ไข:
- FallingObjectFactory.cs 
- SpawnPoints.cs
สิ่งที่เกิดขึ้น:
- ใช้ Factory ในการสร้างวัตถุตกลงมา 
- ลดการใช้ Instantiate กระจายหลายที่  
- เพิ่มไอเทมใหม่ได้ง่ายขึ้น
2) Observer Pattern ใช้อัปเดตคะแนนแบบแยก UI ออกจาก Logic
ไฟล์ที่เพิ่มและแก้ไข:
- GameEvents.cs  
- ScoreScript.cs  
- ScoreUI.cs  
สิ่งที่เกิดขึ้น:
- ScoreScript แจ้ง Event เมื่อคะแนนเปลี่ยน  
- UI Subscribe event เพื่ออัปเดตอัตโนมัติ  
- ลดความ coupling ระหว่างระบบเกมกับ UI
